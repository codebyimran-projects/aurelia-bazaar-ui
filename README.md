# Aurelia Bazaar UI

A modern and visually engaging **single-page e-commerce marketplace UI** designed for a premium bazaar-style shopping experience.

The interface focuses on clean product presentation, colorful category sections, promotional deals, and smooth user interactions while maintaining a polished and responsive layout.

## Project Overview

**Aurelia Bazaar** is a frontend UI concept for an online marketplace where users can explore products, browse categories, discover daily deals, and view promotional collections.

The project was designed and developed by **CodebyImran** using pure frontend technologies.

## Features

- Responsive single-page marketplace layout
- Modern navigation bar
- Hero section with promotional content
- Product and stall search interface
- Category / stall browsing section
- Daily deals section
- Product collection grid
- Discount badges and pricing displays
- Summer sale promotional banner
- "Why Choose Aurelia" feature section
- Bazaar club newsletter section
- Responsive footer
- Interactive UI elements
- Smooth hover and micro-interactions
